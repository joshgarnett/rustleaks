# rustleaks-go

The Go package `github.com/joshgarnett/rustleaks-go` scans bytes for secrets
in process with the Rustleaks engine. See [Using the Go
package](https://github.com/joshgarnett/rustleaks/blob/main/docs/user/go.md)
for installation, examples, options and errors.

The code lives in `bindings/go/` of
[joshgarnett/rustleaks](https://github.com/joshgarnett/rustleaks). Send
issues and pull requests there.

In that repository, run the package tests with:

```sh
just test-go
```
